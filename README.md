# 一加 13 电池解容模块 uv2800（v12 · WebUI 版）说明

一加 13 这块硅碳负极电池的硬件放电下限在 2800 mV 左右，但原厂为了保守起见，随着循环次数增加会把电量计的 0% 空电点和关机电压抬高到 3200~3250 mV 甚至更高，导致明明还有不少电量却提前显示 0% 关机。同时，官方状态栏电量带有一层明显的平滑滞后，高负载掉电时跟不上真实电量；到了 1% 还会强制弹窗切进超级省电模式。

`uv2800` 就是为了解决这几个痛点做的内核级模块。更新到 **v12（versionCode 35）** 后，模块自带了全套 KernelSU WebUI 界面，所有设置和状态查看都可以在管理器里直接完成，不需要再手动改配置文件或敲命令。

---

## 一、 主要功能

1. **自定义关机截止电压（2800–3060 mV）**
   默认设为 **2800 mV**。你可以在 WebUI 里拖动滑块或点快捷按钮随时修改，点击「应用」即可生效，无需重启手机。

2. **电量计空电点自动跟随校准**
   只改关机电压而不改电量计的空电点（Termination Voltage），会导致电量百分比计算失真。模块会根据你设定的关机电压自动派生出电量计的学习终止电压并写入 ADSP，让电量计在满充/放空循环中按新的电压窗口计算容量（FCC）和剩余电量（RM）。

3. **显示电量计真实电量（可在 WebUI 独立开关，默认开启）**
   将电量计真实的 `chip_soc` 挂载到系统 `capacity` 节点，去掉官方平滑算法带来的滞后，掉电和充电显示更线性。

4. **禁止 1% 强制进入超级省电（可在 WebUI 独立开关，默认开启）**
   通过系统设备策略关闭 1% 自动跳转超级省电的限制，1% 电量下依然可以正常使用手机。

## 二、 为什么采用内核挂钩 + 原生电量计方案？

社区里常见改 `dtbo` 或者在系统层重映射百分比的做法，各有明显的局限：
- **只刷修改版 dtbo**：一旦电量计 IC 已经被写入过较高的终止电压，就算刷回原版 dtbo，电量计内部保存的阈值也不会立刻恢复；而且跨系统版本升级时很容易因为设备树表结构微调而算错档位。
- **显示层重映射百分比**：端电压在玩游戏、拍照等高负载场景下会因为内阻产生瞬时压降，单纯按电压去折算百分比会导致电量显示忽高忽低。

`uv2800` 的做法是直接加载一个轻量的内核模块 `uv2800.ko`：
- 一方面通过内核 `kprobe` 和 `vote_override` 接管驱动的关机电压投票与阈值更新；
- 另一方面直接调用驱动内部的读写函数，把派生后的终止电压写进 ADSP 电量计，让高通 QBG 电量计自己在硬件层做库仑积分与容量学习。
- 模块加载时会严格核对驱动函数的机器码指令签名，如果遇到不兼容的内核版本会直接拒绝加载，不会在不匹配的内核上乱改寄存器。同时自适应支持 **ColorOS 15、ColorOS 16 和 ColorOS 17**。

## 三、 使用方法

### 1. 安装与生效
- 手机需已获取 Root 权限并安装 KernelSU（或兼容 WebUI 的管理器），同时支持**标准启动（LKM）**和**越狱注入（late-load）**两种模式。
- 刷入 `一加13解容-v12.zip` 后重启手机。
- **重要提示**：电量计的全充容量（FCC）不会在刚修改完电压的瞬间立刻跳变，它需要在**充满电状态切换**（充到 100% 满充，或满电拔插充电器）以及日常充放电循环中重新锚定。

### 2. 使用 WebUI
在管理器模块卡片上点击打开 WebUI，即可看到：
- **顶部电量卡片**：实时查看电量计真实电量、系统显示电量、当前单芯电压、温度、关机电压、ADSP 空电点、剩余电量（RM）以及电量计真实 FCC。
- **关机电压调节**：拖动滑块在 `2800~3060 mV` 之间选择目标电压，点「应用并重跑 service.sh」立即生效。
- **功能开关**：「显示真实电量」和「禁止 1% 强制超级省电」都可以单独打开或关闭，修改后跨重启持久保留。
- **运行状态与日志**：底部可展开查看驱动连接状态、内核 Profile、绑定状态以及模块运行日志。

## 四、 恢复原厂与卸载步骤（请务必按顺序操作）

因為电量计 ADSP 寄存器里的值是跨重启保持的，**卸载模块前请务必先在 WebUI 里点一次「恢复原厂」**，不要直接删模块：

1. **确保当前电量大于 30%（单芯电压高于 3.30 V）**
   如果在低电量（电压低于原厂空电点，如 3250 mV）时强行把原厂终止电压写回电量计，电量计会立刻判定电池已放空并进入钳位状态（电量直接卡在 0%，需要充满一次电才能恢复）。
2. **在 WebUI 中执行「恢复原厂」**
   打開模块 WebUI，在「恢复原厂」卡片中勾选风险确认，点击「恢复原厂」。模块会优先读取首次安装前备份的原厂值（若无备份则根据当前电池循环次数和温度从设备树精确算出原厂值），将其写回 ADSP 电量计，同时解绑真实电量并恢复超级省电策略。
3. **在管理器中卸载模块并重启**
   看到恢复原厂成功的提示后，再回到管理器勾选卸载模块并重启手机即可。
